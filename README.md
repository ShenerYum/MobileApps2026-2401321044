
# Budgeteer – The Personal Finance Tracker

A personal finance management Android application built with Kotlin.

## 1. Idea

Budgeteer is a mobile application designed to help users manage
their personal finances by tracking income, expenses, budgets,
and financial statistics.

## 2. How It Works

The application allows users to create and manage financial
transactions, organize them into categories, and monitor their
spending through monthly budgets and visual statistics.

Transaction data is stored locally using Room Database.
Currency exchange rates are retrieved through an external REST API.

## 3. Architecture

- Language: Kotlin
- UI: Jetpack Compose
- Design System: Material 3
- Architecture: MVVM
- Database: Room
- Dependency Injection: Hilt
- Networking: Retrofit
- Asynchronous operations: Kotlin Coroutines and Flow
